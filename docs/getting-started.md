# Getting started

Choose a notebook from the [gallery](../gallery.html), or write in the welcome notebook. Run a cell with its ▶ button or Ctrl/Cmd+Enter. Run all follows the notebook's execution mode.

Use **+ Cell** to add Python, Markdown, SQL, R or Raw. R source is preserved, but R execution is disabled in this build. Double-click Markdown to edit it; Escape renders it.

A new notebook is reactive: changing a Python cell schedules its dependents after 750 ms. Turn Auto-run off to edit without executing. Opening imported files always turns Auto-run off. Use Source to edit the whole Notebook Markdown document.

Share copies source and settings into the URL; it does not save outputs. Download as .ipynb to retain current outputs. Use More → Resume saved work for explicit draft recovery.

Code can make network requests. Review code from other people before you run it. A link with `?run=0` opens without execution.
