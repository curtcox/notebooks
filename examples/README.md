# Notebook fixtures

These examples and format fixtures are original Notebook Online examples, MIT licensed under the repository LICENSE. The autodiff example is an original implementation inspired by the public micrograd approach; no micrograd source is copied.

Edit `.qmd` source files and `catalog.json`, then run `node scripts/examples.mjs`, `npm run gallery`, and `npm run offline`. Jupyter and marimo import demonstrations are generated with `node scripts/create-format-examples.mjs`.
